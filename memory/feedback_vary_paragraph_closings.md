When drafting a multi-topic section where each paragraph/topic ends on a relationship-to-own-work sentence, don't default every single one to the same "our verifier / our work extends this" framing. Vary the closing move across topics — one might end on the paper's own contribution, another on the open gap itself, another on a plain contrastive statement without first-person framing at all.

**Why:** Said explicitly while drafting Related Work for [[the-verifier-that-cannot-see]], after Topic 1 and Topic 2 both closed on near-identical "our own verifier extends this... / our verifier is never given..." sentences. Even though each was fine individually, the repeated structure itself reads as formulaic once you see it twice in a row — the same failure mode the humanise-academic skill flags for repetitive paragraph structure generally.

**How to apply:** Before drafting a topic's closing sentence, check how the previous topic closed. If it used first-person "we/our" framing, default to a different closing move for this one — e.g. end on the gap itself (as Topic 3 does, since it's the paper's one honestly open claim), end on a plain contrastive statement, or fold the relationship into an earlier sentence in the paragraph so the last sentence isn't doing that job at all.
